# 📖 CSI-KNC (Konganthanparai North CSI Church App)

Welcome to **CSI-KNC**, the official mobile application of **Konganthanparai North CSI Christ Church** — designed to help members stay spiritually connected through digital access to songs, prayer points, live sessions, and announcements.

---

## ✨ Features

- 📜 **Daily Bible Verse** — Get daily inspiration from the Bible.
- 📢 **Church Announcements** — Stay informed about upcoming church events.
- 💰 **Pending Differentiation** — View and manage your pending dues.
- 🎵 **Song Search & 1000 Praises** — Explore and search among 1000 praises and traditional songs with pagination.
- 🙏 **Prayer Requests** — Submit your prayer needs for church fellowship.
- 📖 **Order of Service** — Access the order of prayers and worship.
- 🎥 **Live Prayer Meetings** — Join live prayer and convention sessions directly from the app.
- ⚙️ **Offline Access** — View stored verses and data even without an internet connection.

## ⚙️ Tech Stack

- **Language:** Kotlin (Jetpack Compose)
- **Database:** Firebase Firestore
- **Auth & Storage:** Firebase Authentication, Cloud Storage
- **UI Framework:** Material 3 + Jetpack Compose Animations
- **Architecture:** MVVM (Model-View-ViewModel)
- **State Management:** Compose + LiveData
- **Pagination:** LazyColumn with animated transitions
